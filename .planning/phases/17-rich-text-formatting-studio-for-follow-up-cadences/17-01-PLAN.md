# Phase 17: Rich Text Formatting Studio for Follow-Up Cadences - Plan

**Phase:** 17  
**Milestone:** v4.0  
**Requirements:** [RICH-01, RICH-02, RICH-03]  
**Status:** In Progress  

---

## Overview

Upgrade `client/src/components/DripSequenceStudio.jsx` from a plain `<textarea>` to a full WYSIWYG rich text formatting studio for all follow-up steps. The editor provides one-click formatting commands (Bold, Italic, Underline, Bulleted List, Numbered List, Link, Clear Formatting), selection-aware variable token insertion (`{{FirstName}}`, `{{Company}}`), and seamless HTML rendering with automatic plain-text fallback generation for dual-part RFC 2046 multipart MIME email dispatch.

---

## Tasks

### Task 1: Rich Text Toolbar & ContentEditable Studio in DripSequenceStudio
**Description:** Implement `FORMAT_BUTTONS`, `RICH_TEXT_CLASSES`, and `toHtml` helper in `client/src/components/DripSequenceStudio.jsx`. Replace the `<textarea>` with a `contentEditable` editor and formatting toolbar.
**Acceptance Criteria:**
- [ ] Add `Bold, Italic, Underline, List, ListOrdered, Link, RemoveFormatting` icons to `lucide-react` imports.
- [ ] Implement `handleFormat(cmd)` supporting standard formatting commands and link insertion prompts.
- [ ] Replace `<textarea>` with a styled `contentEditable` div using semantic tokens and placeholder text.
- [ ] Synchronize `bodyRef.current.innerHTML` on active step tab changes (`activeStepTab`) so each step displays its own formatted copy.
- [ ] Synchronize `bodyRef.current.innerHTML` when loading a template via `handleSelectTemplate`.
- [ ] Update `handleInsertVariable` to insert tokens (`{{FirstName}}`) at the active caret position within the rich editor (or subject line if subject is focused).

---

### Task 2: Backend Dual-Part MIME & Test Send Verification
**Description:** Verify that `server/index.js` and `server/queueService.js` handle HTML follow-up copy with automatic plain-text fallbacks via `templateService.htmlToText`.
**Acceptance Criteria:**
- [ ] `app.post('/api/campaigns/:id/test-send')` passes `stepNumber` to `queueService.sendTestEmail` so step previews test the exact step's copy.
- [ ] Follow-up steps dispatched with HTML tags (`<b>`, `<ul>`, `<a>`) generate both `html` and `text` parts in Nodemailer transport.
