# Phase 21: Native Gmail Auto-Labeling & Thread Organization Subsystem

## Goal
Leverage native Gmail IMAP extensions (`X-GM-LABELS`, mailbox hierarchy creation, and message tag synchronization) to automatically categorize campaign threads, incoming prospect replies, AI sentiment classifications, and bounce reports directly in the user's Gmail inbox under a clean `StrokeCRM/` label hierarchy.

## Requirements
- **GMAIL-01**: Auto-create and manage Gmail label hierarchy (`StrokeCRM`, `StrokeCRM/Replied`, `StrokeCRM/Interested`, `StrokeCRM/Questions`, `StrokeCRM/Follow-Up`, `StrokeCRM/Not-Interested`, `StrokeCRM/Bounced`, and `StrokeCRM/Campaign: [Name]`) via IMAP extensions without interfering with personal user folders.
- **GMAIL-02**: Apply labels to inbound prospect replies matching campaign and AI sentiment, and tag bounce reports (`StrokeCRM/Bounced`) for immediate operator visibility in Gmail.
- **GMAIL-03**: Settings toggle in Account Settings ("Gmail Native Auto-Labeling", default ON) with safe fallback for non-Gmail IMAP accounts.

## Proposed Tasks
1. **Task 1: Gmail Label Management Service (`server/gmailLabelService.js`)**
   - Implement `ensureLabelHierarchy(client, campaignName)`: Safely creates `StrokeCRM`, sentiment folders, and campaign-specific subfolder via `client.mailboxCreate`.
   - Implement `applyLabelsToMessage(client, uid, labels, options)`: Uses `client.messageCopy` / `X-GM-LABELS` with error handling.
   - Implement provider capability detection (`isGmailImap(client)`).

2. **Task 2: Wire Labeling into Inbound Scanner (`server/replyScannerService.js`)**
   - During `scanInboxForReplies`, when a reply is detected:
     - Check `gmail_auto_labeling` setting.
     - Apply `StrokeCRM`, `StrokeCRM/Replied`, `StrokeCRM/Campaign: [Name]`.
     - When AI sentiment is determined (`INTERESTED`, `QUESTION`, `FOLLOW_UP`, `NOT_INTERESTED`), apply the sub-label.
   - When an NDR bounce is detected:
     - Apply `StrokeCRM`, `StrokeCRM/Bounced`, `StrokeCRM/Campaign: [Name]`.

3. **Task 3: Settings Configuration & UI (`server/db.js`, `server/index.js`, `client/src/components/SettingsView.jsx`)**
   - Add `gmail_auto_labeling` column/setting to database (default: 1).
   - Add toggle in `SettingsView.jsx` under Account Settings with explanation and status badge.

4. **Task 4: Automated Verification & Documentation**
   - Create test script verifying label path resolution, fallback handling, and setting persistence.
   - Run Vite build check.
   - Update `.planning/` state and summary.
