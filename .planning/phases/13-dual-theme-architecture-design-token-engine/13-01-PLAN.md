  <action>
    Implement D-05: FOUT Prevention Script and global theme state management.
    1. In `client/index.html`:
       - Update title to `<title>StrokeCRM — Cold Outreach & CRM</title>`.
       - Add synchronous inline script inside `<head>` before any stylesheets or module scripts (satisfies D-05):
         ```html
         <script>
           (function() {
             try {
               var stored = localStorage.getItem('strokecrm_theme');
               var theme = stored || (window.matchMedia('(prefers-color-scheme: light)').matches ? 'light' : 'dark');
               document.documentElement.setAttribute('data-theme', theme);
               if (theme === 'light') {
                 document.documentElement.classList.add('light');
               } else {
                 document.documentElement.classList.remove('light');
               }
             } catch (e) {}
           })();
         </script>
         ```
    2. Create `client/src/context/ThemeContext.jsx`:
       - Manage `theme` state (`'dark'` or `'light'`).
       - On mount, initialize from `document.documentElement.getAttribute('data-theme') || localStorage.getItem('strokecrm_theme') || 'dark'`.
       - Function `setTheme(newTheme)`:
         - Updates `theme` state.
         - Sets `document.documentElement.setAttribute('data-theme', newTheme)`.
         - Updates classList (`'light'` class toggle).
         - Persists to `localStorage.setItem('strokecrm_theme', newTheme)`.
       - Function `toggleTheme()`: switches between `'dark'` and `'light'`.
       - Listen to `window.matchMedia('(prefers-color-scheme: light)')` change events if no manual preference stored in `localStorage`.
       - Expose `useTheme()` hook returning `{ theme, setTheme, toggleTheme, isDark: theme === 'dark' }`.
    3. In `client/src/App.jsx`:
       - Import `ThemeProvider` from `./context/ThemeContext`.
       - Wrap the root component tree with `<ThemeProvider>`.
  </action>
