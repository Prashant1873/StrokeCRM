## Overview

Build an end-to-end, zero-cost email reply sentiment intelligence system. Inbound replies detected by the IMAP scanner are automatically sanitized and classified into 5 outreach categories (`Interested`, `Question`, `Follow Up`, `Not Interested`, `Unsubscribe`) using Google Gemini 1.5 Flash's free REST API tier, with an instant offline regex heuristic fallback engine. Operators can configure and test their free API key in Settings, view color-coded badges and 1-sentence summaries in the Campaign Cockpit, filter leads by sentiment with 1-click tabs, and manually override any classification.

## Tasks

### Task 1: Backend Sentiment Engine Service
**Description:** Implement `server/sentimentService.js` with email quote-stripping sanitization, Google Gemini 1.5 Flash native REST client with JSON schema enforcement, zero-dependency offline heuristic classifier, and API key handshake tester.

**Acceptance Criteria:**
- [ ] `sanitizeEmailBody(text)` cleanly strips `> ` quoted lines, headers like `On ... wrote:`, and trims to safe lengths.
- [ ] `classifyWithHeuristics(text, subject)` accurately categorizes text using keyword patterns with confidence ratings (0.50 - 0.95).
- [ ] `classifyWithGemini(text, subject, apiKey)` calls Gemini 1.5 Flash REST endpoint with JSON mode and returns structured `{ sentiment, confidence, summary }`.
- [ ] `classifyReply(text, subject, { apiKey })` attempts Gemini first (if key provided), falling back gracefully to heuristics on error or timeout.
- [ ] `verifyGeminiKey(apiKey)` sends a lightweight handshake prompt and returns `{ valid, model, latencyMs, message }`.

**Verification:**
- Run isolated Node test script checking heuristic rules and sanitizer outputs.
