# Phase 16: Campaign Duplication Engine & Triad Cloning - Plan

**Phase:** 16  
**Milestone:** v4.0  
**Requirements:** [DUP-01, DUP-02, DUP-03]  
**Status:** In Progress  

---

## Overview

Implement complete campaign and triad duplication capability. Operators can duplicate any existing campaign from the Campaigns Directory (`#/campaigns`) or the Campaign Cockpit (`#/campaigns/:id`), specify a new campaign name, and bind a fresh isolated database (or upload a new spreadsheet inline). The system transactionally replicates all campaign configurations (throttling, jitter, template bindings, A/B testing variants, CC/BCC, accounts) and clones all multi-step drip cadence steps (`campaign_drip_steps`), initializing the clone cleanly in `DRAFT` status with zeroed counters.

---

## Tasks

### Task 1: Backend Duplication API Endpoint
**Description:** Add `POST /api/campaigns/:id/duplicate` in `server/index.js` wrapped in an atomic SQLite transaction (`db.transaction`).
**Acceptance Criteria:**
- [ ] Validates non-empty `name` and valid `database_id`.
- [ ] Validates target database exists and is not currently held by a `RUNNING` campaign.
- [ ] Replicates all campaign settings (`sender_account_id`, `sender_provider`, `subject_a`, `body_a`, `subject_b`, `body_b`, `is_ab_test`, `min_delay`, `max_delay`, `daily_limit`, `template_id`, `cc_addresses`, `bcc_addresses`).
- [ ] Duplicates all rows from `campaign_drip_steps` for the source campaign, re-mapping to the new campaign ID and retaining cadence delays, threading, and copy.
- [ ] Binds the target database (`is_attached = 1`, `campaign_id = newCampaignId`), resets records to `status = 'PENDING'` and `current_step = 1`, and populates `total_contacts`.
- [ ] Returns `{ success: true, campaignId: newId, message }`.

**Verification:**
- Automated test script creating a test campaign with drip steps, calling the duplicate endpoint with a test database, and validating cloned rows in SQLite.

---

### Task 2: Frontend Duplicate Action & Modal in CampaignsView
**Description:** Implement the Duplicate action and interactive modal in `client/src/components/CampaignsView.jsx`.
**Acceptance Criteria:**
- [ ] Add "Duplicate" button with `Copy` icon on each Campaign Card in the Campaigns Directory (`#/campaigns`).
- [ ] Add "Duplicate Campaign" button in the Campaign Cockpit header (`#/campaigns/:id`).
- [ ] Modal displays source campaign name, text input for new campaign name (prefilled as `[Name] (Copy)`), and audience database selector showing unattached databases.
- [ ] Modal includes quick-upload option to drag-and-drop or pick a new `.xlsx`, `.xls`, `.csv` file directly within the modal.
- [ ] Shows clear confirmation summary of cloned configurations (template, cadence steps, delay jitter, daily limit).
- [ ] On submit, calls `POST /api/campaigns/:id/duplicate`, refreshes campaign directory, displays success feedback, and navigates to the new campaign cockpit.

**Verification:**
- Build verification and end-to-end check in browser or via test API calls.
