# Phase 18: System-Wide Light Mode WCAG Contrast & Token Hardening - Plan

**Phase:** 18  
**Milestone:** v4.0  
**Requirements:** [CONTRAST-01, CONTRAST-02, CONTRAST-03, CONTRAST-04]  
**Status:** In Progress  

---

## Overview

Milestone v3.0 introduced a theme toggle and semantic CSS tokens, but several views (`SettingsView`, `ABTestingView`, `Switch`, `CampaignsView`, `DatabasesView`, `CampaignPreflight`) still retain legacy hardcoded dark classes (`bg-slate-900`, `bg-slate-950`, `border-slate-800`, `text-slate-400`, `text-slate-300`, `text-slate-600`). When switching to light mode, these sections render as dark black patches with poor legibility or low-contrast text. Furthermore, in light mode, `--text-muted: #a1a1aa;` has a ~2.8:1 contrast ratio against `#ffffff`, falling short of the WCAG 2.2 AA requirement (>= 4.5:1).

This phase hardens all CSS tokens in `index.css` for both light and dark modes to strictly exceed WCAG 2.2 AA standards, purges all remaining hardcoded `slate-` and `zinc-` utilities across the client components, and standardizes buttons, form inputs, modals, and tables to render with crisp typography and distinct visual affordance in both themes.

## Tasks

### Task 1: CSS Design Tokens & Contrast Hardening (`client/src/index.css`)
- [ ] In `[data-theme="light"]`:
  - Upgrade `--text-muted` from `#a1a1aa` (~2.8:1) to `#64748b` (~4.6:1, WCAG AA compliant >= 4.5:1).
  - Upgrade `--text-secondary` from `#52525b` to `#475569` (~7.1:1).
  - Update `--border-subtle: #e2e8f0;` and `--border-default: #cbd5e1;` for crisp card separation.
  - Update `--scrollbar-thumb: #cbd5e1;` and `--scrollbar-thumb-hover: #94a3b8;`.
- [ ] In `:root, [data-theme="dark"]`:
  - Upgrade `--text-muted` from `#71717a` (~3.6:1 on `#18181b`) to `#a1a1aa` (~6.5:1) to prevent low-contrast text in dark mode.
  - Ensure `--text-secondary` is `#d4d4d8;` (~10.5:1) and `--text-primary` is `#fafafa;`.

1. Toggling to Light Mode shows pristine white/off-white backgrounds (`bg-canvas: #fafafa`, `bg-surface: #ffffff`) with sharp text (`#18181b` and `#475569`), with zero dark black slate blocks in Settings or A/B Testing.
